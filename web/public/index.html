Tentang

AnimeStudio Web adalah tampilan web (mobile friendly) untuk AnimeStudio — tool ekstraksi asset game Unity bikinan Escartem, fork dari Studio (Razmoth) dan AssetStudio (Perfare). Web ini cuma pembungkus: semua pekerjaan berat tetap dijalankan oleh AnimeStudio.CLI.

Lisensi AnimeStudio: MIT. Web wrapper ini juga kamu bebas pakai/modifikasi.

Repo AnimeStudio Wiki resmi Lisensi MIT

Cara pakai (3 langkah)

  1. Pilih game yang cocok dengan file kamu. Ini paling penting — kunci dekripsi beda-beda.
  2. Pilih file/folder bundle Unity yang mau dibongkar. Bisa satu file, banyak file, atau satu folder game utuh.
  3. Mulai ekstraksi, lihat progress di tab Proses, lalu ambil hasilnya di tab Hasil (per file atau sekaligus .zip).

Tips: mulai dari satu bundle kecil dulu untuk memastikan pilihan game-nya benar, baru lanjut ke folder besar.

Cara pasang CLI (sekali saja)

  1. Unduh build resmi (Windows x64, butuh .NET Desktop Runtime yang cocok):
    ⬇️ Build .NET 10 (terbaru) ⬇️ Build .NET 9 (stabil)
  2. Ekstrak isi zip ke folder animestudio-web/bin/AnimeStudio/ — jadi ada bin/AnimeStudio/AnimeStudio.CLI.exe (subfolder juga terdeteksi otomatis).
  3. Muat ulang halaman ini. Indikator di kanan atas berubah jadi hijau “CLI siap”.

Mau pakai build/path lain? Jalankan server dengan AS_CLI="D:\tools\AnimeStudio.CLI.exe" node server.js

Kalau cuma punya HP 📱

AnimeStudio resminya Windows x64 (butuh .NET). Jadi HP-nya dipakai sebagai remote-control saja — CLI-nya harus jalan di suatu tempat “Windows”. Pilihan realistis, dari yang paling gampang:

  1. Tanpa PC sama sekali → GitHub Actions: lihat kartu “🌟 Tanpa PC sama sekali?” di atas. Ini yang paling direkomendasikan kalau kamu cuma punya HP.
  2. Titip jalan di PC (teman/keluarga/warnet): jalankan run-windows.bat, lalu buka alamat http://IP-PC:8787 dari HP yang tersambung wifi sama. Semua proses & hasil tetap di PC itu.
  3. Cloud PC / VPS Windows (mis. Azure, Contabo, Hetzner, layanan RDP lokal): jalankan server di sana, akses lewat browser HP. Cocok kalau mau pakai jangka panjang tanpa PC sendiri.
  4. Android + Termux (eksperimental): cuma bisa kalau build-nya jalan di Wine/Box86-ARM — tidak resmi dan sering gagal. Kalau berhasil pun, kecepatannya jauh di bawah PC.
  5. Minta tolong komunitas: banyak yang sudah punya setup dan mau bantu ekstrak — Discord AnimeStudio.

Catatan jujur: ekstraksi asset game besar (puluhan GB) realistisnya butuh PC/VPS — RAM dan CPU-nya jauh lebih kuat.

🌟 Tanpa PC sama sekali? Pakai GitHub

GitHub punya PC Windows gratis (runner windows-latest) yang bisa menjalankan AnimeStudio. Jadi modalnya cuma akun GitHub + browser HP. Semua bisa dikerjakan dari HP: upload bundle → tekan Run workflow → unduh hasil.

  1. Buat repo private di github.com/new.
  2. Bikin file .github/workflows/extract.yml (isi file ini sudah disiapkan di folder github-extract/ project ini) → Commit.
  3. Releases → Draft a new release → tag v1 → attach file bundle (maks 2 GB/file) → Publish, lalu copy link filenya.
  4. Tab Actions → AnimeStudio Extract → Run workflow: isi kode game (mis. GI) + tempel link bundle → Run.
  5. Tunggu 1–5 menit → hasil otomatis muncul di Releases (dan/atau Artifacts), siap diunduh dari HP.
Runner private repo2 core / 8 GB / disk 14 GB — Windows dihitung ×2 dari kuota 2.000 menit/bulan (efektif ±1.000 menit).
Hasil di atas 450 MBOtomatis ditaruh di Releases (bukan Artifacts) supaya tidak kena kuota storage 500 MB. Hasil > 1,8 GB dipecah otomatis jadi .001/.002.
Repo publikGratis tanpa batas menit + mesin 4 core, tapi jangan pakai untuk asset berhak cipta.

Panduan langkah-per-langkah lengkap: github-extract/README.md. Codespaces tidak bisa dipakai — mesinnya Linux, sedangkan AnimeStudio wajib Windows.

Kalau ada masalah

Invalid Game / hasil sampahSalah pilih entri game. Coba entri lain (mis. GI vs GI_CB3), atau pilih versi Unity yang benar.
0 file / folder hasil kosongFilter jenis asset atau filter nama terlalu ketat, atau bundle-nya memang kosong. Coba Semua jenis dan hapus filter regex.
Progress mentok / lamaBundle besar (ratusan MB–GB) memang butuh waktu. Jangan tutup server. Cek log di tab Proses.
Error MeshRenderer/SkinnedMeshRendererCoba set jenis asset ke Mesh/Texture2D saja, atau lewati export model dan ambil teksturnya.
File > 2 GB gagal uploadUpload dari HP lewat browser rawan putus. Pecah folder jadi beberapa batch, atau taruh file langsung ke folder data/jobs/<id>/input/ di komputer server.
Zip gagal dibuatPastikan ruang disk cukup (zip butuh ~1× ukuran hasil). Coba download per folder saja.

Etika & legal

Ekstrak asset hanya untuk pemakaian pribadi (mod, fanart, riset, belajar). Jangan menyebarkan file mentah milik game atau memakainya untuk hal komersial tanpa izin pemiliknya. Ikuti aturan tiap publisher dan jangan bagikan kunci dekripsi ke pihak yang tidak berkepentingan.
